# Issue tracker: GitHub

Issues for this repo live in GitHub Issues at `naiiytom/jadwai-app`.

## Conventions

- Create issues in this repository's GitHub Issues.
- Read an issue with its comments and labels before acting on it.
- Use native GitHub issue dependencies for blocking relationships when available; otherwise state blockers in the issue body.
- When publishing approved tickets, apply `ready-for-agent` unless instructed otherwise.
- Do not close or modify a parent issue when publishing child tickets.
- PRs are not a request surface for triage.

## When a skill says "publish to the issue tracker"

Create a GitHub issue in `naiiytom/jadwai-app`.

## When a skill says "fetch the relevant ticket"

Read the GitHub issue, including comments and labels.
