# ร่างข้อความตั้งค่าและอุปกรณ์ (ภาษาไทย)

สถานะ: ร่างสำหรับ Phase 0/1 เท่านั้น ยังไม่ใช่ข้อความที่อนุมัติสำหรับ production
ขอบเขต: ป้ายกำกับและคำแนะนำสั้น ๆ สำหรับการตั้งค่าบัญชี, vault และอุปกรณ์; ไม่มีคำแนะนำทางกฎหมายหรือคำรับรองสิทธิประโยชน์

## การตั้งค่าเริ่มต้น

| ID | ข้อความภาษาไทย | ที่มา |
|---|---|---|
| `setup.title` | เริ่มตั้งค่า vault | PRD §4.1 |
| `setup.account` | สร้างบัญชีและตั้งค่าการเข้าสู่ระบบ | PRD §4.1(1), FR-1.6 |
| `setup.passkey` | ตั้งค่า Passkey | PRD §4.1(1), FR-1.6 |
| `setup.mfa_fallback` | หากใช้ Passkey ไม่ได้ ให้ใช้ MFA ตามที่ระบบรองรับ | PRD §4.1(1) |
| `setup.local_keys` | สร้างข้อมูลความปลอดภัยบนอุปกรณ์นี้ | PRD §4.1(2) |
| `setup.local_keys_help` | ข้อมูล vault ที่ส่งไปยังเซิร์ฟเวอร์ต้องเป็นข้อมูลเข้ารหัสและข้อมูลกู้คืนที่ห่อหุ้มไว้เท่านั้น | PRD §4.1(2) |
| `setup.assets` | เพิ่มทรัพย์สินและหนี้สิน | PRD §4.1(3), FR-1.2 |
| `setup.emergency_capsule` | ตั้งค่าข้อมูลฉุกเฉิน (Tier 1) | PRD §4.1(4), FR-1.4 |
| `setup.estate_vault` | ตั้งค่า Estate Vault (Tier 2) | PRD §4.1(4), FR-4.2 |
| `setup.trusted_people` | เพิ่มผู้ติดต่อหลักที่ไว้ใจได้และผู้ติดต่อสำรองอิสระ | PRD §4.1(5) |
| `setup.recovery_kit` | เตรียมชุดกู้คืนของคุณ | PRD §4.1(5), FR-1.6 |
| `setup.coverage_gap` | ดูภาพรวมช่องว่างความคุ้มครองบนอุปกรณ์นี้ | PRD §4.1(6), FR-2.1 |

## การตั้งค่าบัญชีและอุปกรณ์

| ID | ข้อความภาษาไทย | ที่มา |
|---|---|---|
| `device.settings_title` | อุปกรณ์และการกู้คืนบัญชี | FR-1.6 |
| `device.trusted_list` | อุปกรณ์ที่ไว้ใจได้ | FR-1.6 |
| `device.enroll` | เพิ่มอุปกรณ์นี้ | FR-1.6 |
| `device.enroll_notice` | เราจะแจ้งเตือนคุณเมื่อมีการเพิ่มอุปกรณ์ | FR-1.6 |
| `device.revoke` | ถอนสิทธิ์อุปกรณ์นี้ | FR-1.6 |
| `device.replace_passkey` | เปลี่ยน Passkey | FR-1.6 |
| `device.recovery_start` | เริ่มกู้คืนบัญชี | FR-1.6 |
| `device.recovery_key_rotation` | เปลี่ยนกุญแจกู้คืน | FR-1.6 |
| `device.owner_material_notice` | การกู้คืนต้องใช้ข้อมูลกู้คืนที่คุณถือไว้ ทีมสนับสนุนกู้คืนข้อมูลใน vault แทนคุณไม่ได้ | FR-1.6 |

## ข้อความที่ยังต้องผ่าน gate

| พื้นที่ | ข้อความในร่าง | Gate / ที่มา |
|---|---|---|
| ข้อมูลประกัน | `[ข้อความประกัน — รอ config ที่มีแหล่งที่มาและการทบทวนที่กำหนด]` | PRD §4.1(3), `config/README.md`; ห้ามเพิ่มจำนวนเงินหรือข้อความสิทธิ์แบบ hard-code |
| พินัยกรรม / Estate documents | `[ข้อความพินัยกรรม — รอข้อความฉบับที่ที่ปรึกษากฎหมายไทยอนุมัติใน config]` | PRD FR-1.3, §8.4; Phase 0.1 |
| Living Will | `[ข้อความ Living Will — รอข้อความฉบับที่ที่ปรึกษากฎหมายไทยอนุมัติใน config]` | PRD FR-1.4, §8.4; Phase 0.1 |
| สิทธิประโยชน์ | `[ข้อความสิทธิประโยชน์ — รอรายการใน config ที่มีแหล่งที่มา วันที่มีผล และการทบทวน]` | PRD §8.5, `config/README.md` |
| คำขอข้อเสนอ | `Privacy-Limited Quote` (ชื่อเรียกมาตรฐาน; ยังไม่ร่าง CTA หรือข้อความยินยอมในเอกสารนี้) | PRD FR-2.3; ต้องแสดง consent แยกตามวัตถุประสงค์ก่อนส่ง lead |

คำว่า `Estate Vault` และ `Tier 2` เป็นชื่อพื้นที่เก็บข้อมูล ไม่ใช่ข้อความรับรองผลทางกฎหมายหรือการเข้าถึงโดยบุคคลอื่น
